# 📊 Activity 3: Social Media Infographics & Project Documentation

> *Simplifying real-world data into visual stories and proposing technology-driven solutions through structured documentation.*

## 📖 About This Activity

This laboratory activity focused on developing information synthesis, data simplification, and visual storytelling skills through two main outputs: a **One-Page Infographic** that breaks down a real-world problem using data and visual elements, and a **Project Documentation Report** proposing an IT- or technology-enabled solution to address that issue.

## 💡 What Have I Learned?

* **Key Concepts & Skills:** I gained deeper awareness of a real-world problem while learning how to design a topic-relevant infographic and write a structured project proposal and documentation report.

* **Challenges & Solutions:** Fitting all the necessary information onto the infographic without sacrificing its visual appeal was difficult, so I condensed the text into concise points and paired them with visual elements directly tied to the core message.

* **Future Applications:** Moving forward, I can choose a more attention-grabbing color scheme and refine or remove extra visual elements to keep the layout clean and prevent overcrowding.
