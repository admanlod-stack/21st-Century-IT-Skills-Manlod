# 🌐 Activity 6: Making a Website

> *Leveraging AI-powered development tools to design, build, and deploy a functional personal digital portfolio.*

## 📖 About This Activity

In this activity, we used **Replit** alongside artificial intelligence to build and launch a working website from scratch. Using AI-assisted generation, I created a personalized digital portfolio showcasing my background, work, and interests.

## 💡 What Have I Learned?

* **Key Concepts & Skills:** I learned that with the help of AI development tools, it is possible to design and build a fully functional website easily, even without prior coding experience.

* **Challenges & Solutions:** Because the free version of Replit has limited generation attempts, crafting a single prompt detailed enough to produce the exact website I envisioned was challenging—so I used Gemini to help me write a comprehensive, highly specific prompt describing every feature and layout detail I wanted.

* **Future Applications:** Moving forward, upgrading to a paid Replit plan would allow me to iterate without usage limits, expand my portfolio with new features, and maintain the website over the long term.
