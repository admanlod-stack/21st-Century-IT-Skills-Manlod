# 🤖 Activity 5: AI Tools Activity

> *Exploring the impact of prompt engineering on AI image generation by comparing basic inputs with detailed, structured instructions.*

## 📖 About This Activity

This activity focused on using generative AI tools to create well-structured images through intentional prompting. We compared the results of using a brief, basic prompt against a carefully engineered, detailed prompt designed to produce the exact visual output we envisioned in a single command.

## 💡 What Have I Learned?

* **Key Concepts & Skills:** Through prompt engineering, I learned how to structure and personalize detailed instructions so that an AI tool can accurately generate the exact image I want in a single command.

* **Challenges & Solutions:** Crafting a highly specific prompt was challenging because it quickly became overly long and complex, so I solved this by condensing my ideas into three focused sentences that clearly described the exact visual elements I wanted.

* **Future Applications:** Moving forward, I can gradually expand my prompts with even more descriptive details—such as lighting, style, and composition—to maximize the chances of generating an image that perfectly matches my vision.
